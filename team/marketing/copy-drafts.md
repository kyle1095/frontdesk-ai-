Prepared 2026-09-19 by marketing. Canonical link list: `outreach-tracker.csv` (same directory). Angles referenced are playbook §3 (Angles 1 and 3). Every claim below is something the demo verifiably does today — nothing here is a result, metric, or testimonial.

## How to use

1. **You (the owner) send everything, from your own accounts, one-to-one.** The team prepares links and drafts only; nothing has been sent by us and nothing will be. No bulk sends, no purchased lists, no mass DMs.
2. **Pick your row in the tracker, then paste that row's exact link.** Each row has a pre-verified tagged URL in the format `https://f84c49587847aae2d38ee792763f89f2.ctonew.app/?ref=<tag>`. The `?ref=` tag is what records the visit's source on conversations and signups, so using the wrong tag (or no tag) loses the attribution. Need a tag that isn't logged yet? Add a row to the tracker first (tag format: lowercase-with-hyphens, e.g. `email-11`), then use it.
3. **Personalize before sending.** The bracketed `[placeholders]` exist so each message names one real, specific thing about the recipient. A personalized send with a true observation beats a polished generic one.
4. **After you send:** change that row's `status` to `sent by owner` and put the date in `sent_date`.
5. **When a reply comes in, tell the team** — we mark `reply_status` as `owner-reported`. We never record a reply you haven't reported.
6. **Channel performance comes from the operator view's by-source counts** (operator page → conversations/signups by source), never from memory or estimates. Before the first send, record today's operator counts as the baseline (playbook §5, days 1–2) so the by-source numbers can be read cleanly. Nobody on the team invents, rounds up, or projects performance numbers.
7. **Keep messages honest under improvisation.** The "facts you may use" list below is everything the product verifiably does — stick to it. Don't add statistics we don't have, customer counts, testimonials, or urgency ("limited time", "spots filling up"). Every draft already carries the affiliation disclosure and an easy opt-out; keep them when you edit.
8. Personal-send rows have the `angle` column blank — you pick Angle 1 (repeat questions answered from your own content) or Angle 3 (ticket with reference number / call-slot booking) per recipient.
